# フォルダ構成

./
- about/
- articles/
- cgls/
- css/
- games/
- js/
- footer.html
- header.html
- index.html
- readme.md


## about/
　「サークルについて」「行事」「歴史（現在工事中）」のhtmlファイルが置かれています
　都度更新するように

## articles/
　トップページから見れるニュースのページを保管しています
　articles/articletemplateをコピーして、article.htmlを弄ることで新規記事を作成できます
　画像を使用することも可能です
　スタイルを更新したいときはarticles/article.cssを更新してください
　追加した記事はindex.htmlの記事一覧に追加しないと見れないので注意
　記事はイベントがあるごとに都度追加するように

## cgls/
　ロゴ等の基本的な画像の保管場所です
　語源は分かりません
　暇があれば各フォルダのcglsフォルダをimgに改名とかやってもいいかも
　やらなくてもいい

## css/
　基本的なcssを保管しています
　ただし各ページの固有のスタイルに関しては各フォルダに格納しています（articles/article.cssのように）
　気に入らなくなったら改変してください
　現在のcssはWCE（早稲田コンピュータエンターテイメント）のホームページを参考にしています

## games/
